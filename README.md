# اپ اندروید «تحلیل تست کنکور» (Capacitor)

همان اپ HTML شما، داخل یک پوسته‌ی اندروید. **همه‌ی فایل‌ها داخل APK هستند و اپ بدون اینترنت اجرا می‌شود** (اینترنت فقط برای ورود و همگام‌سازی لازم است).

## چرا Capacitor؟ (تصمیم تیم)
| گزینه | نتیجه |
|---|---|
| **Capacitor (انتخاب‌شده)** | همان کد فعلی؛ APK مستقل برای بازار/مایکت؛ بعداً می‌شود افزونه‌ی پرداخت درون‌برنامه‌ای بازار و مایکت را اضافه کرد |
| فقط PWA/وب | نصب از بازار/مایکت ندارد؛ برای هدف شما (حضور در مارکت) کافی نیست |
| TWA (وب‌سایت داخل کروم) | به سرور وب و Chrome نیاز دارد و اتصال به پرداخت درون‌برنامه‌ای فروشگاه‌ها سخت‌تر است |
| بازنویسی با Flutter/Kotlin | چند ماه کار، بدون مزیت فوری |

## آماده‌سازی (یک‌بار)
۱. روی یک کامپیوتر **Node.js (نسخه‌ی LTS)** و **Android Studio** نصب کنید.
۲. در `www/config.js` آدرس سرور را بنویسید (مثلاً `https://api.example.ir`).
۳. در `capacitor.config.json` مقدار `appId` را به شناسه‌ی یکتای خودتان تغییر دهید (مثل `ir.yourbrand.konkur`). **بعد از انتشار اول، دیگر قابل تغییر نیست.**
۴. در `.env` سرور (`konkur-api`) این آدرس را به `ALLOWED_ORIGINS` اضافه کنید: `https://localhost` (مبدأ داخلی اپ اندروید).

## ساخت APK
```bash
npm install
npm run vendor          # Tailwind/Chart/FontAwesome/فونت را محلی می‌کند
npm run android:add     # فقط بار اول
npm run assets          # آیکون‌ها را از resources/icon.png می‌سازد
npm run android:sync
npm run android:open    # Android Studio باز می‌شود
```
در Android Studio: `Build > Generate Signed App Bundle / APK` و گزینه‌ی **APK** را انتخاب کنید. یک **Keystore** می‌سازید؛ **آن را و رمزش را در چند جای امن نگه دارید**. اگر گم شود، دیگر نمی‌توانید به‌روزرسانی بدهید.

> اگر با این مراحل راحت نیستید، همین پوشه را به یک برنامه‌نویس اندروید بدهید و بگویید: «این پروژه‌ی Capacitor است؛ APK امضاشده بساز و روی گوشی تست کن.» برای کسی که این کار را بلد است معمولاً کمتر از چند ساعت است.

## قبل از انتشار حتماً روی گوشی واقعی چک کنید
- [ ] بدون اینترنت: ثبت تست، تایمر، داشبورد کار می‌کند
- [ ] ظاهر: نوار بالا و پایین زیر نوار وضعیت/ناوبری سیستم نرفته باشد
- [ ] ورود با پیامک واقعی، خروج، ورود دوباره، بستن و باز کردن اپ (نشست باقی بماند)
- [ ] همگام‌سازی بین دو گوشی
- [ ] دکمه‌ی Back: مودال‌ها را می‌بندد و در صفحه‌ی اصلی از اپ خارج می‌کند
- [ ] چرخش صفحه و اندازه‌ی کوچک (۳۶۰px)

## انتشار در بازار و مایکت
۱. در پنل توسعه‌دهندگان **هر دو** ثبت‌نام کنید (مدارک هویتی طبق راهنمای خودشان).
۲. APK امضاشده، آیکون، اسکرین‌شات و متن‌ها (`store-listing.md`) را بارگذاری کنید.
۳. **همیشه با همان Keystore** نسخه‌های بعدی را امضا کنید و `versionCode` را زیاد کنید.
۴. نسخه‌ی اول را به چند دوست بدهید و بعد منتشر کنید.

## موضوع مهم: پرداخت اشتراک (مرحله‌ی ۵)
- بازار و مایکت **پرداخت درون‌برنامه‌ای مخصوص خودشان** را دارند (برای بازار کتابخانه‌ی Poolakey؛ خرید اشتراک را هم پشتیبانی می‌کند و نیاز دارد اپ بازار روی گوشی نصب و وارد شده باشد).
- **قبل از طراحی پرداخت، قوانین و کارمزد فعلی هر دو فروشگاه را از پنل/مستندات رسمی‌شان بخوانید.** اینکه استفاده از درگاه خودتان (زرین‌پال) داخل اپ مجاز است یا باید پرداخت فروشگاه استفاده شود، را من تأیید نکرده‌ام و روی قیمت و درآمد اثر مستقیم دارد.
- طرح پیشنهادی: خرید از طریق پرداخت هر فروشگاه + تأیید رسید خرید روی سرور ما (کلاینت هرگز «Premium» اعلام نمی‌کند)؛ و در نسخه‌ی وب، زرین‌پال.
- بازار «ورود درون‌برنامه‌ای» هم دارد که می‌تواند جای پیامک را بگیرد (هزینه‌ی پیامک صفر). فعلاً سراغش نرفتیم چون هویت کاربر را به بازار وابسته می‌کند.

## محدودیت‌های شناخته‌شده
- توکن ورود روی نسخه‌ی اندروید در حافظه‌ی خصوصی خود اپ نگه‌داری می‌شود (برای گوشی‌های غیر روت امن است). ارتقا به Android Keystore در نسخه‌های بعد.
- فقط اندروید. iOS با این پروژه ممکن است ولی خارج از بازار/مایکت است.
- نسخه‌ی Capacitor (۷) از حافظه انتخاب شده؛ اگر نسخه‌ی جدیدتر آمد، طبق راهنمای ارتقای رسمی بروز کنید.


## قابلیت‌های جدید نسخه پیشنهادی

### ۱) کلیدخوان هوشمند AI
در صفحه تست‌زنی، کاربر می‌تواند از صفحه «کلید پاسخ» کتاب عکس بگیرد. اپ تصویر را به `POST /v1/ai/answer-key` می‌فرستد و پاسخ استاندارد زیر را دریافت می‌کند:

```json
{
  "answers": [
    { "testNo": 1643, "option": "2", "confidence": 0.98 },
    { "testNo": 1644, "option": "4", "confidence": 0.96 }
  ]
}
```

سرور باید احراز هویت و وضعیت Premium/Trial را بررسی کند. **کلید API مدل AI هرگز نباید در APK یا JavaScript قرار بگیرد.** پیشنهاد فنی: OCR/vision + یک مرحله اعتبارسنجی ساختاری JSON؛ اگر confidence پایین بود، آن مورد به کاربر نشان داده شود تا قبل از اعمال تأیید کند.

### ۲) نتیجه خودکار پارت
بعد از اعمال کلید، پاسخ‌های ثبت‌شده‌ی کاربر با کلید تطبیق داده می‌شوند و وضعیت «درست/نادرست» خودکار می‌شود. درصد پارت نیز قبل از ذخیره نمایش داده می‌شود.

### ۳) چالش‌ها
چالش‌های اولیه:
- ۵۰۰ تست در ماه
- ۱۰۰ تست در ۷ روز
- ۷ روز فعال
- ۲۰ تست با ثبت علت خطا
- رسیدن به ۱۰۰ تست در یک درس

برای جلوگیری از فشار روانی، شکست چالش هیچ جریمه‌ای ندارد و streak با یک روز استراحت از بین نمی‌رود.

### ۴) Premium آزمایشی
پیشنهاد محصول: برای هر حساب تازه‌ثبت‌نام‌شده، سرور **۷ روز Premium Trial** فعال کند. مقدار `plan` می‌تواند `trial` و `planExpiresAt` تاریخ پایان باشد. فعال/منقضی‌شدن Trial باید سمت سرور enforce شود؛ localStorage نباید منبع حقیقت اشتراک باشد.

## ساخت APK بدون نصب Android Studio روی کامپیوتر شخصی
فایل `.github/workflows/build-apk.yml` اضافه شده است. با push پروژه به GitHub، از بخش **Actions** می‌توانید workflow ساخت APK را اجرا کنید و APK آزمایشی را به‌عنوان Artifact دریافت کنید. برای انتشار رسمی در بازار/مایکت، APK باید با Keystore اختصاصی خودتان sign شود؛ Keystore و رمز آن را هرگز داخل repository قرار ندهید.
